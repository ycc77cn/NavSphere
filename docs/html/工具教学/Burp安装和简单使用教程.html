杨CC有话说

Burp破解版安装和简单使用教程，本教程用于Windows。MAC、Linux请自行查找对应教程。

如果需要深入使用,请等待杨CC更新~

下载安装包。

  • 打开ycc资源站
  • 右上角搜索框，搜索：Burp Suite-25.9破解版
  • 如图：
  • 随后下载对应的apk，如果是Windows，则下载Windows，如果是mac，就下载mac版本。
  • 我们这里以Windows为例

解压

  • 我们打开文件下载位置以后，
  • 点击：查看 -》 勾选上显示扩展名 ，如下图：
  • 随后我们会看到：下载的文件是下面的名称：
  • 右键 》 重命名 》删除.apk
  • 然后解压到一个自己喜欢的地方即可。
  • 解压后如图：
  • 到此,解压完成

安装环境(必须,不然会报错)

  • 打开java jdk 21 目录.
  • 双击打开里面唯一的一个exe文件.
  • 注意,目录的话,可以改,可以不改,如果你是小白,则不要更改.
  • 打开终端(cmd\powershell都可以)
# 输入
java --version

# 输出如下,则为正确
java 21.0.2 2024-01-16 LTS
Java(TM) SE Runtime Environment (build 21.0.2+13-LTS-58)
Java HotSpot(TM) 64-Bit Server VM (build 21.0.2+13-LTS-58, mixed mode, sharing)
  • 如图
  • 到这里,环境安装成功

安装

  • 找到解压目录,地址栏输入:cmd然后回车.
  • 然后会出现下图:
  • 可能略有偏差,不过没关系,按照下面步骤一点一点来即可.
java --version # 检查java环境 如果没有输出,或者报错,请回到上方安装环境的步骤.
java -jar BurpSuiteLoader1.jar # 运行破解器
# 运行破解器后,会出现下图

  • 点击 run
  • 会出现一个新的界面.具体操作看下图
  • 再然后,就激活成功,进来了.

汉化

  • 先关闭打开的所有的终端以及软件.
  • 回到解压的目录中.
  • 找到:BurpSuiteLoader.vbs
  • 然后双击运行.就会出现软件界面
  • 启动Burp
  • 就进入了咱们的软件了.

创建桌面快捷方式.

  • 再次回到解压的目录.

  • 找到:创建桌面快捷方式.bat

  • 双击运行,即可

  • 随后,你就可以正常的从桌面启动Burp,愉快的渗透了.
