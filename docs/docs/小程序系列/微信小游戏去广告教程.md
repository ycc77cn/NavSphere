# 原理

- 当我们想要知道如何去广告之前
- 我们需要优先明白去广告的原理
- 小程序中有一个东西，叫做`权重`

- 权重这种东西是系统自动判断的
- 那么我们的核心原理就是去`权重`
- 我们的`权重`越低看广告概率越低

- 我们的`权重`越高看广告概率越高
- 权重低，有好处但同样也有坏处
- - 好处就是不需要再看广告了
  - 坏处则是无法通过广告赚钱
- 权重高，同样如此，与上方相反
- 也就是说，权重高，看广告钱多
- 同时玩小游戏的时候广告会巨多
- `我们今天来讲解的就是降低权重`
- 大概需要3天时间。

## 运行时长说明

- `注意`:观看广告时间,可能会随着权重不同,而有不同的时间.24小时为一个周期
- `注意`: 当没有广告后,一定不要点击分享!!!!!!!!!,不然会回升权重..

- 第一天(0-24小时内):
  -  `第一次`,一般运行6-8个小时之后,会提示没有广告.可以在等待1-2个小时后,再进行观看广告.
  - `第二次`,大概会在持续观看1-2个小时后,提示没有广告,然后再等待1-2个小时.如果运气比较好的话,可能会在3-4个小时后,才会有广告,需要自己测试.
  - `第三次`,一般情况下,只能看30分钟左右的广告,随后正常情况下,今天几乎就不会再有广告了.
  - `第四次`,极少数情况下,会需要看第四次,一般第四次都很短,30-1个小时左右.
  - `更多的次数`,这种情况下几乎不会有,除非你看一半,你不看了,退出了,就可能会产生更多的次数,时长也不同

- 第二天(24-48小时)):
  - `第一次`,可能会在4个小时左右,如果自身权重比较低,可能就是2个小时左右.不排除有更低的.随后可能会有4-6个小时的真空期,会提示没有广告可以看.
  - `第二次`,大概会在1-2个小时左右的广告,随后又会进入无广告模式,大约在4-8个小时为无广告模式,甚至会更久,或者更早.
  - `第三次`,可能只会让你观看10-20个广告左右,随后12小时内,几乎都不会再有广告了.但是需要注意,权重不同,时长可能会变长,或者变短.
  - `第四次`,一般不会出现,如果出现了,只能说明两个原因,一个是自身权重太重,要么就是中间看一半,没看了,如果第二天看一半不看了,权重会回升.
- 第三天(48-72小时):
  - `第一次`,需要先去看运行点击器,让他自动看广告,一般都是几十分钟.
  - `第二次`,然后,你需要更换链接,继续看一个新小游戏广告,中间不需要有间隔.(如果你想在去广告的过程中赚点广告钱,那么请移动到本文的"看广告赚点收益",在文章末),如果不需要,可以自己寻找一个小游戏,重新设置点击器,运行.
  - `第三次`,当你第二次提示无广告后,那么就需要时不时去运行一下看广告的脚本,直到一整天都提示:无广告观看,请分享.
- 到此其实就已经没有广告了,如果有的话,应该也是很少了,每天看慢,第四天就遇不到了,`如果你的权重特别重,则会可能会在3-5天内,才能完成无广告.`
